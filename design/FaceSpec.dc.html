Face format · v1

A face is a JSON file of layers

Each layer type maps to one Kotlin composable already in the launcher. Values in braces are live bindings. Coordinates use a 400-unit grid ("size"); the renderer scales to the real 360 px screen, so one face file fits any round watch. No script runs on the watch — the file is data, so a bad face can't crash the launcher or drain the battery.

Pipeline

01
Write JSON — or TSX on a PC that compiles to JSON
02
Push to /faces via adb or a phone link
03
Parse + validate (kotlinx.serialization)
04
Render on one Compose Canvas; hot-reload
