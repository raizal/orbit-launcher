Voice notes · watch side

Record in one press. Never lose a note.

The watch only records, names, queues and sends. All thinking — transcription and the diary — happens on the companion. A note is deleted from the watch only after the server confirms it has the exact same file.

1 · Ways to start recording

  1. BACK button on the face — one press, no looking.
  2. Mic slot on the face — one tap.
  3. Center of the app grid — home, then tap.
  4. Later, optional: hold BACK from any app, via an accessibility service.

Recording runs in a foreground service with a partial wake lock, so it keeps going with the screen off and survives the launcher being closed.

2 · The file

2026-11-13_12-08-42+0700.m4a
2026-11-13_12-08-42+0700.json

Name = the moment you pressed record, local time + offset. Sorts by name, readable, safe on every filesystem (no colons). AAC-LC, 16 kHz, mono, 32 kbps ≈ 14 MB per hour — good for speech-to-text. Android 8.1 cannot write Opus, so m4a.

{
  "id": "0193c2a4-7f1e-7c3a-9b1d-5e2f8a6c4d10",
  "started_at": "2026-11-13T12:08:42+07:00",
  "duration_ms": 14230,
  "sha256": "9f2c…e81a",
  "device": "H10",
  "location": { "lat": -7.26, "lon": 112.75, "acc_m": 900 }
}

Location is optional and coarse. The JSON is the truth — file times can change when copied.

3 · Finding a server

FIRST
Last known IP, then mDNS
Cached address first; then _orbitnotes._tcp via NsdManager
THEN
Subnet scan
Probe port 8765 on the /24, 32 at a time, 300 ms timeout
ONCE
Pairing
QR with name + token. Watch remembers the home Wi-Fi; never scans other networks

4 · Upload API

GET  /v1/health?nonce=N   → { "name", "api": 1, "proof": HMAC(token, N) }
HEAD /v1/notes/{id}       → 200 already have it · 404 send it
PUT  /v1/notes/{id}       multipart: audio + meta.json
     Authorization: Bearer <token>
     → 201 { "id": "…", "sha256": "…" }

PUT with the note's own id is safe to repeat: a retry after a dropped Wi-Fi connection never makes a duplicate. The proof check stops another device on the network from pretending to be the server.

5 · Send rules

  1. Local only: sends only on the paired home Wi-Fi, never on LTE. One WorkManager job per note; retries 30 s → 1 h; also runs when that Wi-Fi connects.
  2. Plain HTTP on the LAN; allow cleartext for local addresses only (network security config).
  3. Marked sent only when the server's sha256 matches.
  4. Sent notes stay 7 days, then delete. Unsent notes are never deleted.
